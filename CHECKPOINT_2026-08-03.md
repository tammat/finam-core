## Операционный остаток

Обновлённый `finam-v5-bars-fast.service` требует однократной установки с root:

```bash
sudo install -m 0644 /opt/finam-core/deploy/systemd/finam-v5-bars-fast.service /etc/systemd/system/finam-v5-bars-fast.service
sudo systemctl daemon-reload
sudo systemctl restart finam-v5-bars-fast.timer
```

До установки MX был обновлён контрольным ручным запуском; остальные загрузчики
и витрина работают штатно.
