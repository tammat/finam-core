ПРАВИЛО ПРОЕКТА

Любой новый Epic начинается
не с UI и не с кода.

Сначала необходимо ответить
на три вопроса.

1.

Каким образом Epic увеличивает прибыль?

2.

Каким образом Epic уменьшает риск
потери прибыли?

3.

Какое управленческое решение
сможет принять оператор
после реализации Epic?

Если ответа нет хотя бы
на один вопрос,

Epic не начинается.

ПРИНЦИП РАЗВИТИЯ MARKETCORE

Каждый следующий Sprint
должен повышать эффективность
Profit Factory.

Любая функция,
которая не увеличивает прибыль
или не помогает принять решение,
увеличивающее прибыль,

имеет низкий приоритет.
