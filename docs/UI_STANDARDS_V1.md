Цель

==============================================================================

Полностью отделить внутренние коды платформы от пользовательского интерфейса.

Ни один экран платформы не имеет права отображать внутренние значения PostgreSQL,
Enum или Runtime напрямую.

Весь пользовательский интерфейс работает исключительно через слой локализации.


==============================================================================

RULE 1

Любой пользовательский текст только через I18N

==============================================================================

Запрещено

    title = "Feature Store"

    title = "Стратегии"

    title = "Проверка"

Разрешено

    display_label("feature.store.title")

    display_label("strategy.platform.title")

    display_label("edge.validation.title")


==============================================================================

RULE 2

Статусы никогда не отображаются напрямую

==============================================================================

Запрещено

    row.status

    str(status)

    enum.value

Разрешено

    display_status(status)

или

    display_label(f"status.{status}")

==============================================================================

RULE 7

Все Enum являются внутренними кодами

==============================================================================

База данных хранит

    READY

    FAILED

    LONG

    SHORT

    ACTIVE

    DISABLED

    HEALTHY

    WAIT_SAMPLE

Пользователь никогда не видит эти значения напрямую.

UI всегда использует локализованное представление.

RULE 11

Общие слова существуют только один раз

==============================================================================

Например

common.save

common.cancel

common.refresh

common.search

common.enabled

common.disabled

common.ok

common.error

Нельзя создавать

feature.save

risk.save

strategy.save

RULE 13

Code Review

==============================================================================

Считается ошибкой

    row.status

    str(enum)

    enum.value

    "Feature Store"

    "READY"

    "FAILED"

    "LONG"

    "SHORT"

    LABELS_RU

    LABELS_EN

Допускается только

    display_label()

    display_status()

    display_health_status()

    display_pipeline_status()

    display_signal_direction()

    display_action()


==============================================================================

RULE 14

Поддержка нескольких языков

==============================================================================

Добавление нового языка не должно требовать изменения:

    Business Logic

    PostgreSQL

    Platform API

    Strategy

    Risk

    Trading

Меняется только словарь локализации.
