# MARKETCORE_UI_INFORMATION_ARCHITECTURE_V1

## Цель

Привести UI MarketCore к структуре рабочего места аналитика.

Экран допускается в основной интерфейс только если отвечает на конкретный пользовательский вопрос.

## Инженерный режим

Все страницы, которые отражают историю разработки, диагностику, тестовые контуры, OOS, robustness, timers, paper monitors и внутренние очереди, не должны отображаться в основном меню.

Они могут быть доступны только через инженерный режим.

## Правило отдельной страницы

Новая страница допускается только если:

1. есть самостоятельный пользовательский сценарий;
2. сценарий нельзя решить существующей страницей;
3. страница не является техническим checkpoint-экраном;
4. есть provider;
5. есть component;
6. есть i18n;
7. есть route healthcheck;
8. нет runtime/execution coupling.
