# MARKETCORE OS UI GUIDELINES V1

Версия: 1.0

Статус: Architecture Freeze

---

# Назначение

MarketCore OS — основной пользовательский интерфейс платформы MarketCore.

8088 остается рабочим Dashboard.

MarketCore OS развивается как полностью самостоятельный UI-продукт.

---

# Главная цель

За 15 секунд пользователь должен понимать:

- состояние капитала;
- состояние Profit Engine;
- состояние Research;
- состояние Risk;
- что необходимо сделать сейчас.

---

# Основные требования

- Responsive First
- API First
- Widget First
- Mobile First
- Readability First

---

# Языки

Обязательно:

- Русский
- English

Архитектура должна позволять добавление новых языков без изменения Backend.

Все строки UI должны храниться только в словарях локализации.

---

# Часовые пояса

Все данные хранятся:

UTC

Отображаются:

в выбранной пользователем зоне.

Минимально поддерживаются:

- UTC
- Europe/Moscow
- Europe/London
- America/New_York
- Asia/Tokyo

---

# Валюта

Базовая валюта системы:

RUB

Пользователь может выбрать отображение:

- RUB
- USD
- EUR
- CNY

Источник курса:

Официальный курс ЦБ РФ.

Правила:

- Все расчеты выполняются в RUB.
- UI выполняет только отображение в выбранной валюте.
- При отсутствии курса отображается RUB.
- Торговые решения не принимаются на основании конвертации UI.

---

# Навигация

Левый верхний угол:

☰ Главное меню

Первый уровень:

- Home
- Capital
- Edge
- Research
- Intraday
- Portfolio
- Risk
- Program
- Settings

На мобильных устройствах используется выезжающее меню.

---

# Главное правило отображения

Название всегда слева.

Значение всегда справа.

Пример:

Capital                               500 000 ₽

Working Edge                                   3

Paper                                       READY

Runtime                                        OFF

Execution                                     OFF

Никогда:

Capital
500000

или

Paper
READY

---

# Цветовые правила

READY       — зеленый

ACTIVE      — синий

WARNING     — желтый

BLOCKED     — красный

OFF         — серый

---

# Home

Главный экран обязан показывать:

- капитал
- прибыль
- рабочие edge
- research
- paper
- production
- риск
- следующее действие

---

# Карточки

Каждая карточка имеет одинаковый формат:

Label...............................Value

Status..............................READY

Никаких значений под названием.

---

# Responsive

Поддерживаются:

Desktop

Laptop

Tablet

Phone

Без горизонтальной прокрутки.

---

# Mobile

На телефоне:

- большие карточки;
- значения справа;
- меню слева сверху;
- Home всегда доступен;
- Back всегда доступен;
- swipe используется только как дополнительная навигация.

---

# Архитектура UI

UI работает исключительно через API.

UI никогда не обращается напрямую к PostgreSQL.

Схема:

UI

↓

REST API

↓

Services

↓

PostgreSQL

---

# Widget Architecture

Каждый экран состоит из независимых Widget.

Минимальный набор:

Capital Widget

Edge Widget

Research Widget

Risk Widget

Program Widget

Intraday Widget

Portfolio Widget

---

# Program Board

MarketCore OS должен отображать состояние программы развития.

Пример:

Platform

Research

TOP3

Paper

Production

Capital

Intraday

---

# Запреты

Запрещается:

- смешивать Dashboard 8088 и MarketCore OS;
- отображать значения под названием;
- использовать PostgreSQL напрямую из UI;
- создавать страницы без практической пользы;
- добавлять функции, не влияющие на управление капиталом.

---

# Главный принцип

MarketCore OS — рабочее место управляющего капиталом.

Каждый экран обязан помогать принять хотя бы одно решение:

- по капиталу;
- по edge;
- по риску;
- по исследованиям.

Иначе экран не включается в систему.
