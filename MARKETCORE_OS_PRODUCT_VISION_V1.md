# MARKETCORE OS PRODUCT VISION V1

Версия: 1.0

Статус: Architecture Freeze

Дата: 2026-07-02

---

## Что такое MarketCore OS

MarketCore OS — это операционная система управления капиталом.

Это не торговый терминал.

Не торговый робот.

Не Dashboard.

Не административная панель.

MarketCore OS является единым рабочим пространством пользователя, в котором принимаются решения по управлению капиталом, торговыми преимуществами, исследованиями, рисками и внутридневной торговлей.

---

## Главная миссия

Построить систему, которая помогает пользователю непрерывно увеличивать капитал при контролируемом риске.

Главной ценностью системы является не количество функций, а способность помогать принимать качественные решения.

---

## North Star

Каждый квартал система должна становиться объективно лучше как инструмент управления капиталом.

Критерием развития является не количество нового кода, а практический результат.

---

## Главная цель пользователя

Открыв MarketCore OS утром, пользователь должен менее чем за 15 секунд понимать:

- состояние капитала;
- состояние Profit Engine;
- состояние рабочих Edge;
- состояние исследований;
- состояние риска;
- следующее рекомендуемое действие.

---

## Для кого создаётся система

Основной пользователь:

Управляющий собственным капиталом.

В будущем допускается работа нескольких пользователей с разными ролями.

---

## Основные принципы

### Capital First

Любое решение оценивается с точки зрения влияния на долгосрочный рост капитала.

### Simplicity First

Интерфейс обязан быть максимально простым.

Каждый экран отвечает только на один вопрос.

### Readability First

Пользователь должен понимать состояние системы без изучения отчётов.

Главная информация отображается сразу.

### Decision First

Каждая страница должна помогать принять конкретное решение.

Если страница не помогает принять решение — она не должна существовать.

### Widget First

Весь интерфейс строится из независимых Widget.

Каждый Widget отвечает только за одну функцию.

### API First

UI работает исключительно через API.

Прямой доступ UI к PostgreSQL запрещён.

## Стратегическая цель

Через один год MarketCore OS должна стать единственным интерфейсом ежедневной работы пользователя.

SSH и Bash должны использоваться только для разработки и администрирования.

Все ежедневные операции должны выполняться через MarketCore OS.
